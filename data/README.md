\# Dataset Information



This project was developed for the \*\*Comment Category Prediction Challenge\*\* on Kaggle.



The original competition datasets are intentionally \*\*not included in this repository\*\*.



\## Dataset Overview



The competition data contains approximately:



\- 198,000 training records

\- 102,000 test records

\- 4 target classes

\- Textual features

\- Numerical features

\- Categorical features

\- Date and time-related information



\## Data Used in the Project



The modelling workflow works with both textual and structured information, including:



\- Comment text

\- Vote-related information

\- Date and time features

\- Engineered numerical features

\- Categorical features



\## Privacy and Competition Data



The original Kaggle datasets are excluded from this public repository.



This repository contains the \*\*analysis and modelling workflow\*\*, documentation, and project notebook rather than the original competition data.



To reproduce the analysis, obtain the permitted competition data from Kaggle and update the dataset paths in the notebook according to your local environment.



\## Reproducibility



The notebook documents the data preparation, feature engineering, NLP processing, model training, validation, hyperparameter tuning, and ensemble-learning workflow used for the project.
